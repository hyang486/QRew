# Qrew title fonts

Bundled handwriting fonts for screen titles (Qrew redesign unit 1). Both are licensed under the
SIL Open Font License 1.1; the full license text is next to each font. Loaded at runtime with
`expo-font` (`useFonts`), so no native rebuild is needed.

| File | Family key | Use | Source | License |
|---|---|---|---|---|
| PatrickHand-Regular.ttf | `QrewHand` | Latin titles | github.com/google/fonts `ofl/patrickhand` | PatrickHand-OFL.txt |
| Gaegu-Light.ttf | `QrewHandKo` | titles with Hangul (has Latin too) | github.com/google/fonts `ofl/gaegu` | Gaegu-OFL.txt |

The design PDF (Qrew_heytea_UI.pdf) uses Apple's Noteworthy Light, which is not redistributable and has
no Hangul; these are the closest OFL handwriting faces.
